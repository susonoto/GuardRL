# Project status and implementation boundaries

This repository is a starter scaffold intended for learning and extension.

| Capability | Status |
|---|---|
| HTTP event ingestion | Implemented |
| Feature extraction | Implemented, basic |
| Isolation Forest scoring | Implemented with synthetic baseline |
| Calibrated attack probability | Not implemented |
| Verified employee authentication | Not implemented |
| Server-side role-based authorization | Not implemented |
| Human decision endpoint | Implemented, but identity is not verified |
| Simulated block records | Implemented |
| Real firewall changes | Not implemented |
| Durable alert recovery | Not implemented |
| Production-grade database | Not implemented |
| RL training loop | Not implemented; only a feedback-count policy heuristic |
| Verified detection accuracy | Not measured |
| Comprehensive security tests | Not implemented |

Please keep this table updated as capabilities change.
